# E-Commerce Webpage (Group 3 - Project 1)

A feature-rich, responsive online store landing page built strictly with **pure HTML5 and CSS3** (No JavaScript or external frontend frameworks).

## 🚀 Project Overview
This project satisfies all requirements for **Group 3 (Project 1)**:
- **Product Categories Grid**: Department browsing with category cards (Laptops, Audio, Wearables, Cameras, Gaming, Sneakers).
- **Hero Promotional Banner**: Large format promotional showcase with discount bursts, highlighted specs, and immediate shop actions.
- **Featured Products Section**: Comprehensive catalog of product cards with rating star indicators, review count tags, original vs discounted prices, and *"Add to Cart"* buttons.
- **Special Offers & Bundles**: Cross-sell promotional banner highlighting cyber bundle deals and cashback incentives.
- **Customer Reviews Section**: Verified customer testimonials with rating stars, reviewer avatars, and buyer feedback.
- **Shopping Benefits Strip**: Highlighting free shipping, SSL secure payment guarantees, 30-day easy returns, and round-the-clock live support.
- **Newsletter Subscription**: Lead capture discount section.
- **Comprehensive E-Commerce Footer**: Brand summary, payment method badges (Visa, Mastercard, PayPal, Apple Pay), and categorized resource links.

## 🛠️ Built With
- **HTML5**: Semantic document tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<del>`, `<footer>`).
- **CSS3**:
  - CSS Custom Variables for uniform color palettes and consistent elevation shadows.
  - Responsive multi-column layout using CSS Grid and Flexbox.
  - Interactive search bar and filter chip styles.
  - Pure CSS responsive mobile navigation toggle.
  - Google Fonts (`Inter`).
